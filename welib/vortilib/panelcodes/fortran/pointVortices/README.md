# point vorticies 2D panel method ("Jerboa")

This library layer provides tools for 2D panel methods using 2d point vortices, based on the method introduced by Lewis.

NOTE: most of it is present in welib.vortlib.panelcodes.pointVortices.py except for the axisymmetric "duct" elements.

Naming: jerboa is a small omnivor, like a jumping mouse. It's small/low-level, like chipmunks. They live in deserts which to some extent can be seen as flat surfaces...
